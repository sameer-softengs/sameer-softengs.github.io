# Sameer Softengs Portfolio Website

The source repository for my personal portfolio website, published through GitHub Pages.

## Overview

This site presents my background, technical interests, selected projects, and ways to get in touch. The custom domain is configured through the repository’s `CNAME` file.

## Deployment

The site is deployed using GitHub Pages. Changes pushed to the configured publishing branch are published according to the repository’s Pages settings.

## Local Development

```bash
git clone https://github.com/sameer-softengs/sameer-softengs.github.io.git
cd sameer-softengs.github.io
```

Open the site files with a local static server or your preferred development workflow.

## Maintenance

Keep content current, optimize media assets, and verify responsive behavior before publishing changes.
